# M5 图片识别

M5 将图片识别限定为“导入候选 → 用户确认 → 新增课程”。识别不会替换当前课表，也不会把原图、Base64、原始模型响应或 API Key 写入 `.scalendar`。

## 使用流程

1. 先创建或打开一个 `.scalendar` 项目；可在“节次与时间”中补充学校、校区和学期周数。
2. 进入“导入课表”，选择或拖拽 PNG、JPG、JPEG、WEBP 图片。
3. 预览确认图片后，点击“开始识别”。选择图片本身不会自动发起网络请求。
4. 在识别完成页检查课程、周次、节次和标记为“待确认”的字段。
5. 点击确认导入。识别结果会作为新课程追加到当前项目；需要修正的课程可以继续通过课程 Drawer 编辑。

## OpenAI 配置与隐私

M5 使用 OpenAI Python SDK 的 Responses API 图片输入和严格 JSON Schema 输出。API Key 由设置页输入，或者从当前进程的 `OPENAI_API_KEY` 环境变量读取；设置页输入的 Key 仅保存在本次运行的内存中，关闭程序后不会恢复。模型可由 `OPENAI_MODEL` 或设置页指定，默认值为 `gpt-5.5`。

图片只在用户点击“开始识别”后发送给配置的识别服务。项目文件只保存结构化课程，不保存图片副本、Base64、原始请求或原始响应。网络、Key、配额、模型和输出解析错误会显示为可理解的界面提示。

## 保守规则

- 无法确认的字符串输出为空字符串；无法确认的数字保留为 `null`，并写入 `needs_review_fields`。
- 识别层不会根据学校常识猜教室、周次、教师、星期或节次。
- 支持每周、单周、双周和明确列出的自定义周次。
- 规范化阶段会做范围校验和完全重复去重。
- 缺失数字导入 Core 时使用可编辑的明确占位值，同时保留待确认字段和提示；这些值不是识别事实。

## 测试与限制

自动化测试使用 `FakeRecognitionProvider` 和假的 Responses 客户端，不会调用真实 API，也不会消耗额度。真实 API smoke test 需要用户自行提供 API Key、安装 `openai` 依赖并手动确认图片可以发送。

当前限制包括：M5 只有 OpenAI Vision provider；没有本地 OCR、表格线定位、文字框可视化或多图拼接；图片质量、合并单元格、复杂单双周文字和不同学校排版仍需人工确认。Excel、ICS、地图位置解析、邮件推送和 EXE 打包不属于 M5。
