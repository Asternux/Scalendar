# Excel Import / Export（M6）

M6 使用 `.xlsx` 作为人工整理和交换格式。`.scalendar` 仍然是 Scalendar 的唯一真相源；Excel 导入不会静默覆盖当前项目，而是先展示候选课程，再由用户确认追加。

## Scalendar 标准工作簿

标准导出包含两个 Sheet：

- `Courses`：每行一门课程，列为 `课程名称`、`星期`、`开始节次`、`结束节次`、`开始周`、`结束周`、`周期`、`指定周`、`学校`、`校区`、`教学楼`、`教室`、`地点`、`教师`、`备注`。
- `Settings`：项目名、学期名、第 1 教学周周一、总周数、学校、校区，以及节次编号、开始时间、结束时间和名称。

周期使用人类可读值：`每周`、`单周`、`双周`、`自定义`。自定义周期的指定周使用逗号分隔，例如 `1,3,7`。星期使用 `周一` 到 `周日`。

导出不会写入内部 Course UUID、识别状态、图片、API Key 或其他运行时字段。重新导入会生成新的课程 UUID；这是交换格式的预期行为，不会影响原 `.scalendar` 项目中的稳定 ID。

## 导入策略

带有 `Courses` 和 `Settings` 的工作簿走标准 Level 1 路径，要求必要列、日期、周数、节次和周期值可验证。空白项目导入标准工作簿时，会同时恢复项目名称、学期设置、学校/校区和节次时间。

没有标准 Sheet 时，Level 2 只尝试少量明确的常见列名别名，例如“课程名称/课程名”“星期/星期几”“开始节次/开始小节”。字段不完整的课程仍可进入候选，但会标记为“待确认”；无法判断课表结构时会显示明确错误，不会导入猜测结果。

常见错误包括：文件损坏、缺少必要 Sheet、缺少必要列、单元格格式错误、周次或节次越界、无课程和无法识别的结构。导入成功后课程追加到当前项目，原有课程不会被覆盖。

## 当前边界

M6 只支持标准 XLSX，不处理旧式 `.xls`、CSV、在线表格、公式计算结果依赖或合并单元格课表的复杂推断。ICS 导出和 Windows EXE 已在 M7/M8 提供；邮件推送、订阅源和地图位置解析仍属于后续阶段。
